# PT 시간표 건수 카운터

엑셀(.xlsx) 시간표를 브라우저에서 읽어 치료사별 1대1 / 1대다 치료 건수를 계산하는 정적 페이지.
서버·저장소 없음. 코드에 이름·시간표 등 민감정보 없음.


외부 의존성은 JSZip(cdnjs) 하나뿐. 오프라인용으로 쓰려면 `jszip.min.js`를 같은 폴더에 두고 `<script src>` 경로만 바꾸면 된다.

## 사용
1. 같은 날짜의 7·8·9·10팀 시간표 xlsx를 전부 올린다 (FES 교차참조 때문에 타팀 파일 필요).
2. 카운팅할 팀을 고르고 **계산**.
3. 상단 요약표 + 하단 시간표. 각 칸 아래 **왼쪽 = 1대1, 오른쪽 = 1대다**.

## 판독 규칙 (counter.js `DEFAULTS`, UI에서 수정 가능)
| 표기 | 해석 |
|---|---|
| `FES7-1` (치료사 칸) | 7팀 시간표의 `FES7-1` 열, 같은 시간 행의 환자 수만큼 **1대다** (빈칸이면 0) |
| `G홍길동`, `M홍길동` (접두 알파벳) | **1대다** 1건/명. 접두가 G·M 외이면 "기타" 표시 |
| `홍길동N`, `홍길동BN` (접미 알파벳) | **1대1**. 2글자면 앞=동명이인, 뒤=치료코드 |
| `홍길동F` / `홍길동BF` | 1대1 FES → 1대1로 세고 `F` 표시 |
| 장비명 줄이 같은 칸에 있음(`*홍길동` + `족저압3`, `*김은숙F` + `신장B`) | 1대1 "기타". 이때 이름 뒤 알파벳 1글자는 동명이인 표기 |
| `SHEN N`, `G SHEN` (영문 이름) | 한글 이름과 동일 규칙 |
| `/한인숙B N` (띄어쓰기) | 공백 무시 후 판독 → 1대1 |
| 회색 글꼴 | 부도 → 0 (글자 단위로 판정) |
| 검정 + 취소선 | 반부도 → 0.5 |
| 헤더 회색 | 연차 → 열 제외 (아래 환자명이 있어도 안 셈) |
| 헤더에 괄호 (`김효정B(통증)`, `신하린(8병동팀)`) | 자동 제외. 설정의 열 체크를 풀면 포함 가능 |
| 헤더 없는 열, 고정지원, 검색 | 무시 |
| `9팀`, `(월수금)`, `(8병동)`, `RG`, `1335`, 장비명… | 주석으로 무시 |
| `점심`, `접수`, `건수` 행 | 무시 |

회색 판정: 글꼴색을 RGB로 환산해 R≈G≈B이고 검정/흰색이 아니면 회색 (팀마다 다른 회색 tint도 커버).
